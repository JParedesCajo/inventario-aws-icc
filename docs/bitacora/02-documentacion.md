# Sprint 1 — Avance 03: Documentación de Arquitectura

## Objetivo

Documentar la arquitectura AWS del Sistema Web de Gestión de Inventario y establecer los componentes priorizados para su implementación mediante Terraform.

## Actividades realizadas

1. Identificación de los componentes del diagrama AWS.
2. Clasificación de servicios por función.
3. Definición de los componentes priorizados para la implementación.
4. Documentación de las limitaciones de la etapa actual.
5. Revisión de consideraciones de seguridad y costos.

## Archivos involucrados

- `docs/arquitectura.md`
- `docs/bitacora/02-documentacion.md`
- `docs/alcance.md` (ajustes de terminología del proyecto)

## Responsabilidades contempladas

- Arquitectura de soluciones: diseño y documentación.
- Infraestructura: redes y conectividad.
- Seguridad: protección y controles de acceso.
- Cómputo: servicios de aplicación.
- DevOps: automatización y control de versiones.

Estas responsabilidades describen las áreas de trabajo del proyecto.

## Validación

- Revisión de la correspondencia entre el documento y el diagrama AWS.
- Verificación de los componentes priorizados.
- Comprobación de que no se presentan recursos pendientes como implementados.

## Evidencia

- Documento de arquitectura en Visual Studio Code.
- Historial Git del avance.

## Resultado esperado

Arquitectura documentada y alcance técnico establecido para comenzar la codificación de Terraform.

## Próximo avance

Configuración del proveedor AWS mediante Terraform.
